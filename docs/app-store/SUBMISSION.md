# SteelBuild Pro App Store submission

The current cross-platform preparation checklist and build instructions are in [READINESS.md](READINESS.md), assessed on 2026-09-22.

The app uses Capacitor. The repository contains shared native bootstrap code, iOS permission/privacy templates, and an Android project. An iOS Xcode project still needs to be generated and configured on a Mac.

Use the readiness checklist for signing, current SDK requirements, reviewer access, store disclosures, payment eligibility, deletion verification and device testing. The previous runbook overstated completion: billing suppression alone does not guarantee a sign-in-only experience, installed plugins do not prove native functionality, and a privacy template is not a completed disclosure.

Do not submit until those checks are complete. Keep account credentials, signing keys and reviewer passwords outside Git.
